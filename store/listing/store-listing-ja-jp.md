# Microsoft Store Listing Draft

## Product name

Browser Switcher

## Short description

インストール済みブラウザのWindows既定アプリ設定をtrayから開けます。

## Description

Browser Switcherは、複数のブラウザを使い分けるWindowsユーザー向けの小さなtrayユーティリティです。

インストール済みブラウザをtrayメニューに表示し、現在の既定ブラウザにマークを付けます。ブラウザを選ぶと、そのブラウザに対応するWindowsの既定アプリ設定ページを開きます。

Browser Switcherは既定アプリの関連付けを直接変更しません。最終的な変更はWindows設定画面でユーザーが行います。

## Feature bullets

- Windows trayからインストール済みブラウザへアクセス
- 現在の既定ブラウザをメニュー内に表示
- Windowsの既定アプリ設定ページをすばやく開く
- 大きなメイン画面を持たない、軽量なtrayユーティリティ
- 既定アプリの関連付けを直接変更しない

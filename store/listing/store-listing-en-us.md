# Microsoft Store Listing Draft

## Product name

Browser Switcher

## Short description

Open Windows Default Apps settings for your installed browsers from the tray.

## Description

Browser Switcher is a small Windows tray utility for people who regularly work with multiple browsers.

It shows installed browsers in a tray menu, marks the current default browser, and opens the matching Windows Default Apps settings page when you choose a browser.

Browser Switcher does not change default apps directly. It sends you to Windows settings so you stay in control of the final change.

## Feature bullets

- Access installed browsers from the Windows tray
- See which browser is currently the default
- Open the right Windows Default Apps settings page quickly
- Works as a focused tray utility without a large main window
- Does not modify default app associations directly

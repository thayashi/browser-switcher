# Browser Switcher Privacy Policy

Effective date: June 15, 2026

Browser Switcher is a Windows tray utility that helps users open Windows Default Apps settings for installed browsers.

## Information the app accesses

Browser Switcher runs locally on your Windows device. To show the browser list and the current default browser, the app reads browser registration and default app information from Windows system settings and the Windows registry.

This information may include installed browser names, browser registration identifiers, executable paths, icon paths, and the current default browser association for web links.

## Information the app collects or transmits

Browser Switcher does not collect, store, sell, or transmit personal information.

Browser Switcher does not use analytics, advertising, tracking, telemetry, or third-party data collection services.

Browser Switcher does not upload your browser list, default browser setting, files, browsing history, or any other device data to Toshi Software or to any external server.

## How information is used

The information read from Windows is used only on your device to:

- Display installed browsers in the tray menu
- Mark the current default browser
- Open the appropriate Windows Default Apps settings page

Browser Switcher does not directly change default app associations. Any final change is made by the user in Windows settings.

## Support communications

If you contact Toshi Software for support, we may receive the information you choose to provide in that support request, such as your message, contact details, screenshots, or diagnostic details. That information is used only to respond to your request.

## Changes to this policy

This privacy policy may be updated if Browser Switcher changes how it handles data. The latest version will be provided with the Microsoft Store listing or other official product information.
